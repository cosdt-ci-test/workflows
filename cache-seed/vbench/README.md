# VBench LaVie human_action cache seed

This bundle contains only the five unmodified official LaVie videos for
`A person is strumming guitar`, with original indices 0–4. It is the one-Prompt
Quick Start subset, not the full benchmark or a synthetic replacement.

## Provenance

- Dataset: [Vchitect/VBench_sampled_video](https://huggingface.co/datasets/Vchitect/VBench_sampled_video).
- Revision: `8c89bb0218a12323d04821d11ec03c780d0dfb9c`.
- Original paths: `lavie/human_action/A person is strumming guitar-[0-4].mp4`.
- Total size: 1,386,427 bytes; five 16-frame, 512×512 videos.
- Retrieved through authorized upstream downloads. On 2026-10-15, every file's
  size and SHA256 were verified against that revision's official LFS metadata,
  and all 80 frames were decoded locally. No video was re-encoded or renamed.
- `manifest.yaml` was generated by `scripts/bundle_cache.py`, not hand-written.

The upstream [dataset card](https://huggingface.co/datasets/Vchitect/VBench_sampled_video/blob/8c89bb0218a12323d04821d11ec03c780d0dfb9c/README.md)
declares `license: mit`. Its access notice states:

> You agree to not use the data to conduct experiments that cause harm to human subjects.

Keep the upstream attribution, license declaration and usage notice with the
bundle. The license metadata here describes the dataset, not VBench's source
code license.

## Delivery

`projects/vbench/scripts/prepare_assets.py` invokes the existing shared seeder
with `--projects vbench --root "$VBENCH_CACHE_DIR"`. In the VBench Quick Start
workflow, that root is `/root/.cache/vbench`, mounted from
`/data/ci-cache/vbench`. Do not seed it into the generic workflow's default
Hugging Face cache root instead.

The five manifest entries are checked before delivery; the shared seeder
verifies SHA256, skips matching cached files, and restores corrupt ones from
the bundle. The subsequent preparation step checks video decoding. Invalid
bundles fail the job rather than falling back to a different dataset.

No authentication files, HF download metadata or model checkpoints are bundled.
For the rebuild commands, see [the project README](../../projects/vbench/README.md).
