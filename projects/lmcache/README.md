# lmcache

昇腾侧 KV 缓存实现在社区仓库 [LMCache/LMCache-Ascend](https://github.com/LMCache/LMCache-Ascend)。主仓 [LMCache/LMCache](https://github.com/LMCache/LMCache) 没有 NPU 实现。

项目表分类：**推理加速**，支持程度：**新兴适配**。

**本仓不落地 Quick Start / example 看护。** 上游 README 已有 [Getting Started](https://github.com/LMCache/LMCache-Ascend#getting-started)（vLLM-Ascend / SGLang / MindSpore 安装与用法），并自带 CI（[`code-quality.yml`](https://github.com/LMCache/LMCache-Ascend/actions/workflows/code-quality.yml)）。请直接照上游文档操作。
